Waiting for Star Citizen

The game’s telemetry port is closed until you enable it and spawn your character.

4.10.3 LIVE

Close the game and the RSI Launcher, including its tray icon. In PowerShell:

setx GRPC_CLIENT_SERVER_ENABLED true

Start the launcher after that, then the game. The launcher only passes the variable on if it was opened afterwards. To turn it off later:

[Environment]::SetEnvironmentVariable("GRPC_CLIENT_SERVER_ENABLED", $null, "User")

5.0 PTU

Add one line to user.cfg in that channel’s folder, for example C:\Program Files\Roberts Space Industries\StarCitizen\PTU\user.cfg.

server.game.telemetry.enabled=1

After launch, Game.log in the same folder should mention GameTelemetryService and 127.0.0.1:2942. The stream starts once your character has spawned. Commands such as emotes and ship toggles exist on this build; 4.10.3 LIVE is display only.

Schema not extracted yet

Pitboard will not guess the game’s protobuf layout. Star Citizen embeds it in StarCitizen.exe. From this folder, in PowerShell:

python tools\extract_proto.py --exe "C:\Program Files\Roberts Space Industries\StarCitizen\LIVE\Bin64\StarCitizen.exe"

That writes schema\extracted\, which stays on this machine and is not committed. Then start Pitboard again. To click around first, use python -m pitboard --mock.
